auth flow:
1. user creates api key in dashboard
2. user hits auth/token endpoint with api key in authentication headers to get jwt
3. jwt is passed in with authentication headers in actual request to authenticate the call
 - this will require some adjustments to the security config, we need to use the jwt to authenticate the call and ensure it represents the user
4. once authenticated, using an account id we add a redis key "rate_limit:account:acc_123" with a set containing pairs (timestamp, request_id)
5. we then remove old entries that are outside the window, count the total valid requests, compare to the limit, and reject or add the request accordingly
